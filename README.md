# 📚 EduMindAI

EduMindAI is an Offline Hinglish Study Assistant built using Llama 3.2, Retrieval-Augmented Generation (RAG), FAISS, and Streamlit.

## Features

- 📄 PDF Question Answering
- 🤖 Llama 3.2 (1B)
- 🔍 Semantic Search using FAISS
- 🇮🇳 Hinglish Responses
- 💻 Fully Offline

## Tech Stack

- Python
- Streamlit
- Ollama
- Llama 3.2 (1B)
- Sentence Transformers
- FAISS
- PyMuPDF

## Installation

```bash
pip install -r requirements.txt
```

Install the Ollama model:

```bash
ollama pull llama3.2:1b
```

Run the application:

```bash
streamlit run app.py
```
